## Technology Stack

- **Frontend**: Angular
- **Backend**: .NET Core / C#
- **Database**: PostgreSQL
- **PWA**: Firebase Cloud Messaging (FCM)
- **Deployment**: Docker, CI/CD

## Getting Started

### Prerequisites
- Node.js (for frontend)
- .NET 6+ (for backend)
- PostgreSQL
- Docker (optional)

### Development Setup

```bash
# Backend
cd backend
dotnet build
dotnet run

# Frontend
cd frontend
npm install
npm start
```
